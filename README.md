Simple Profit Analysis Using Microsoft Excel
Project Type: Beginner Data Analysis Project
Dataset: Superstore sample data (practice dataset)
Tool Used: Microsoft Excel
1. Introduction
This project demonstrates a simple profit analysis using Microsoft Excel. The goal was to compare profit
across three product categories—Furniture, Office Supplies, and Technology—and identify which category
had the highest profit in the values recorded during the exercise.
2. Objectives
• Organize and review Superstore practice data in Excel.
• Use a PivotTable to summarize profit by product category.
• Compare the profit values for Furniture, Office Supplies, and Technology.
• Identify the category with the highest profit in the analysis.
3. Methodology
The CSV practice dataset was opened in Excel. A PivotTable was created, Category was added to the Rows
area, and Profit was added to the Values area. The resulting category totals were read and compared.
4. Results

Finding: Technology had the highest reported profit value (210), followed by Furniture (62) and Office
Supplies (40). These are the values reported during the practice exercise and have not been independently
recalculated from the PivotTable.
5. Conclusion
The exercise provided practice in using Excel PivotTables to summarize and compare data. Based on the
reported values, Technology was the highest-profit category. This report uses a practice dataset and should
be treated as a learning exercise rather than an analysis of the official Superstore dataset.
